## Featured Projects

### [ragit — Domain-Agnostic RAG Toolkit](https://github.com/eslam-aboutaleb/ragit)

A reusable Python toolkit for building retrieval-augmented generation systems without coupling core retrieval machinery to a particular application domain.

- Document chunking, embedding interfaces, and pluggable vector-store backends.
- Hybrid retrieval combining vector similarity with lexical search strategies.
- Idempotent ingestion, background embedding jobs, and stale-job recovery.
- Retrieval evaluation with metrics such as Precision@K, Recall@K, and MRR.

**Stack:** Python · SQLAlchemy · PostgreSQL/pgvector · Qdrant · Chroma · FAISS · pytest  
[Explore the repository →](https://github.com/eslam-aboutaleb/ragit)

### [Polymarket AI Trading Bot & Research Workspace](https://github.com/eslam-aboutaleb/polymarket-ai-trading)

An AI-assisted workspace for prediction-market research, portfolio monitoring, strategy experimentation, and trading automation.

- Research agents for market context, news, sentiment, and trader activity.
- Strategy workflows for copy trading, market making, inverse positioning, and latency-arbitrage research.
- Paper trading and backtesting to evaluate strategy behavior before live execution.
- Portfolio analytics, execution monitoring, configurable risk limits, and stop-loss/take-profit controls.

**Stack:** Python · FastAPI · React · PostgreSQL · Redis · Docker · LLM integrations · Polymarket/Polygon  
[Explore the repository →](https://github.com/eslam-aboutaleb/polymarket-ai-trading)

<sub>Built for research and strategy experimentation. Historical backtests and AI-generated analysis do not guarantee future trading results.</sub>

### [Insurance Claims RAG Assistant](https://github.com/eslam-aboutaleb/insurance-claims-rag-assistant)

A full-stack assistant prototype for a fictional insurer, demonstrating how domain-grounded AI can work with validated business workflows.

- Policy-coverage answers with source citations and hybrid retrieval.
- Agent tools for claim-status lookup and validated, two-step claim submission.
- Authentication, streaming responses, audit events, and database-backed workflows.
- Retrieval evaluation and tests for important API and security boundaries.

**Stack:** Python · Google ADK · LiteLLM · FastAPI · PostgreSQL/pgvector · React · Docker Compose  
[Explore the repository →](https://github.com/eslam-aboutaleb/insurance-claims-rag-assistant)

<sub>Demonstration project using synthetic data; it is not affiliated with a real insurance company.</sub>

### [Ace Your Interview](https://github.com/eslam-aboutaleb/ace-your-interview)

An adaptive interview-preparation platform combining AI-assisted practice and structured learning across backend, frontend, system design, and AI engineering.

- Level-aware question and quiz generation with source-grounding checks.
- FSRS-based spaced repetition and flashcards with Anki interoperability.
- Mock interview sessions with rubric-based feedback.
- RAG chat, learning progress, and a React-based user experience.

**Stack:** Python · FastAPI · React · TypeScript · RAG · MCP · LLM integrations · Docker  
[Explore the repository →](https://github.com/eslam-aboutaleb/ace-your-interview)

### [Workshop Reservation Service](https://github.com/eslam-aboutaleb/Workshop-reservation)

A full-stack booking system focused on transactional correctness, concurrency, and safe retries.

- Capacity-safe reservations designed to prevent overselling under concurrent requests.
- Idempotency keys for retry-safe operations.
- User-scoped reservation access and administrator controls.
- Server-Sent Events for live availability updates, with database migrations and tests.

**Stack:** Python · FastAPI · PostgreSQL · React · Docker Compose · pytest  
[Explore the repository →](https://github.com/eslam-aboutaleb/Workshop-reservation)
